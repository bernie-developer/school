# School Hub

[English](../readme.md) • [Español](readme.es.md) • **Nederlands**

Interactief leermateriaal voor kinderen, gestructureerd rond schoolvakken. Momenteel gericht op Engels (getallen, grammatica en woordenschat).

## Modules

- **Engelse Getallen** — kleurrijke tabel van 1 tot 20
- **Getallen Quiz** — willekeurige quiz waarbij leerlingen het getal typen dat hoort bij een Engels woord
- **Talenten Test** — mini-test over grammatica en actiewoorden (likes/doesn't like)

Meer modules volgen.

## Installatie

Download de bestanden en open `index.html` in de browser — geen server nodig.

Om de CSS opnieuw te compileren na wijzigingen:

```bash
npm install
npm run build:css
```

## Technologie

- Vanilla JavaScript, HTML, CSS
- Tailwind CSS (gecompileerd, geen CDN)
- Fonts lokaal geladen (geen internet nodig)
- LocalStorage voor taalvoorkeur
- Beschikbaar in Engels, Spaans en Nederlands
